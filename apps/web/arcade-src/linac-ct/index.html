    Complete every prescribed field before closing the treatment session and posting the technical treatment-delivery charge.
    Field-level delivery mode. Select the prescribed field, then independently set the machine to that field’s geometry. Beam enable validates field identity, gantry, collimator, jaws, MLC, couch, verified IGRT when prescribed, imaging hardware retracted, current collision clearance, and Motion Enable locked. Rotating photon/VMAT fields also require full trajectory clearance; a verified static electron field uses a fixed-pose cone/patient/table clearance check because the gantry and treatment couch remain stationary during irradiation. A documented simulation-only clearance override applies to both the current mechanical-clearance proxy and the complete selected treatment trajectory, including dynamic arc clearance and stereotactic dry-run trajectory holds. It does not bypass any non-clearance interlock and requires explicit OIS/R&V acknowledgment before final sign-off. AP/PA and opposed-lateral fields must therefore be delivered at their corresponding beam orientations. For dynamic IMRT/VMAT, the learner verifies the start geometry; after beam-on, the treatment control sequence drives only the prescribed gantry/MLC/dose-rate motion for that field.

    2026 treatment-delivery categories · conventional and stereotactic

    77402Level 1 delivery
    Basic radiation treatment deliveryUsed for lower-complexity delivery such as a single electron field, multiple electron fields, or 2D photon treatment. Imaging guidance is included when performed.Think: conventional 2D fields or electron treatment.
    77407Level 2 delivery
    Single-isocenter 3D CRT or IMRT photon deliveryUsed for photon treatment delivered to a single isocenter using 3D conformal radiation therapy or IMRT. Imaging guidance is included when performed.Think: one isocenter + 3D CRT/IMRT, without the Level 3 features below.
    77412Level 3 delivery
    Higher-complexity radiation treatment deliveryUsed for multiple-isocenter photon therapy, or single-isocenter photon therapy with active motion management; it also includes total-skin electrons or mixed electron/photon fields. Imaging guidance is included when performed.Think: multiple isocenters, active motion management, total-skin electrons, or mixed modalities.
    77371SRS · cobalt-60
    Single-session cranial stereotactic radiosurgery using a multi-source cobalt-60 unitThis is an SRS treatment-delivery code for cranial lesion treatment performed on a multi-source cobalt-60 platform rather than a medical linear accelerator.Think: cranial SRS + multi-source cobalt-60 system.
    77372SRS · LINAC
    Single-session cranial stereotactic radiosurgery delivered on a linear acceleratorThis is the stereotactic treatment-delivery code that corresponds to a one-session cranial SRS course performed on a medical LINAC.Think: cranial SRS + linear accelerator.
    77373SBRT · per fraction
    Stereotactic body radiation therapy treatment deliveryUsed per fraction for stereotactic treatment of one or more extracranial lesions in a course of no more than five fractions; the descriptor includes image guidance.Think: extracranial stereotactic treatment · 1–5 fractions.
    How to choose: identify the treatment technique first, then ask whether it is 2D/electron, single-isocenter 3D/IMRT, or a Level 3 situation such as multiple isocenters or active motion management.
    IGRT note: handling depends on the treatment-delivery family. Conventional treatment, cranial SRS, and SBRT have different descriptor/guidance instructions in the supplied CPT material; the simulator explains the rule used for the loaded case.
    Treatment management: 77427 is shown for conventional courses; stereotactic cranial SRS uses a different management code. This simulator's charge-posting step focuses on the technical treatment-delivery session and displays the applicable management code for context.
