DICOM MPR Alignment Lab
Browser-based teaching prototype for CT/CBCT review, multi-planar reconstruction, click-button couch-shift practice, and lightweight 3D maximum-intensity projection.
1 · Load CT image set
Drop a folder/ZIP of de-identified CT DICOM slices here, or choose files.
The same uploaded series becomes the reference CT and simulated moving CBCT with randomized offsets.
2 · Moving-image simulation
After upload, the platform classifies the set automatically. A multi-slice CT series opens in volumetric MPR mode. A DICOM image tagged as LOCALIZER or described as a scout/topogram opens in planar-registration mode. The reference is duplicated as the moving daily image and given a hidden random setup offset.
Advanced optional: load a second DICOM series as the moving/daily image set.

Integration notes
A topogram/localizer is treated as a planar setup image, not as volumetric CBCT. Multi-slice CT/CBCT data use MPR mode. Mount this page/module from the OIS Imaging button or LINAC image-guidance panel. Emit the approved shifts to your treatment console as {lat, vrt, lng, roll, pitch, yaw}. Compressed transfer syntaxes may need Cornerstone image loader/GDCM later; this prototype directly supports common uncompressed CT files.
